# 使用指南

从“曲库”导入并加载动作，使用底部播放条检查时间和姿态，再在“动作”“镜头”“舞台”调整演出。首次使用请先完成[安装](INSTALLATION.md)。

## 打开面板

进入偶像摄影后，按 `Ctrl+M` 唤出或唤回 GakuMotion 控制窗口。当前仅允许已识别的偶像摄影场景和经页面状态确认的更衣室；主页、Live、培育和未知页面禁用控制，已保存的设置保留。部分摄影背景尚不在准入范围，以面板的页面状态提示为准。

GakuMotion 接管期间会阻断游戏的手动拍照入口。停止表演、恢复原生状态后再使用原生拍照。

迁移前曲库根为 `gakumas-local/motions`，完成[分类目录迁移](MIGRATION_LAYOUT.md)后为 `gakumas-local/UserData/gakumotion/motions`。一个曲目是该根的直接子目录，备份和迁移应保留整个目录及 `.gakumotion-trash` 恢复区。

## 添加与管理曲目

1. 在“曲库”点击“+ 添加到曲库”，选择身体动作 VMD。
2. 在弹窗中分别指定表情、镜头和音乐；可用“+ 追加文件...”从其他文件夹补充素材。
3. 输入曲名，点击“添加”，等待导入完成。
4. 选中曲目，点击“加载预览”检查静止姿态，或“播放选中”开始演出。

| 输入 | 支持与默认行为 |
| --- | --- |
| 动作 | 含身体骨骼关键帧的 `.vmd`，新增曲目时必选 |
| 表情与眼动 | 独立 `.vmd`，或自动沿用身体 VMD 自带的表情；可选择不导入 |
| 镜头 | 含镜头关键帧的 `.vmd` 或已烘焙的 `.gkcamera`，可不导入 |
| 音乐 | PCM `.wav`；自动模式查找身体 VMD 同名 WAV 或其旁边的 `song.wav`，也可选择不导入 |

支持文件拖入的 GakuLoader 版本可将多个 VMD、GKCamera、WAV 拖到曲库列表，打开同一个添加窗口；确认前不会导入。其他宿主版本继续使用文件选择器。

修改已有曲目使用“管理选中”，再点击“保存修改”。保留轨道与清除轨道是不同选项，请按弹窗中的文字选择。新增曲名冲突时应改名，更新已有版本使用管理入口。

在磁盘外部新增、删除或修改动作后，点击“刷新曲库”更新列表。刷新保留正在使用的已加载表演；需要应用当前曲目的文件改动时，点击“重新加载当前曲目”，它会保留时间并保持静止：原本播放或暂停时进入暂停，原本停止或预览时进入预览。列表单击只选择条目，不会切换当前表演。

曲库管理提供两种操作：

| 操作 | 文件与恢复方式 |
| --- | --- |
| 从列表移除 | 仅隐藏条目，所有本地文件保留；点击“恢复已移除曲目”重新显示 |
| 删除本地文件 | 先显示曲名与目录确认；确认后将整个曲目目录移入曲库的 `.gakumotion-trash`，可用“恢复最近删除”找回 |

关闭确认窗或点击取消不会改动文件。可恢复区仍占用磁盘空间；恢复时如原位置已有同名曲目，会保留双方并提示冲突，不覆盖新文件。迁移或备份时复制整个动作目录，播放列表 JSON 本身不包含动作资源。

## 播放与逐帧检查

底部播放条在各页面保持可见，支持播放、暂停、停止、上一曲和下一曲，以及播放一次、单曲循环、列表循环和随机轮播。

- 拖动进度条，或输入秒数、`mm:ss.mmm` 后按 Enter／“定位”，跳到指定时间；Esc 取消输入。
- “动作帧”按当前动作的实际采样帧率换算，首帧为 0，末帧为总采样帧数减 1。
- 输入动作帧号，或点击“上一帧”“下一帧”，会先暂停并静默定位。
- 播放栏提供 0.1、0.2、0.5、0.8、1、1.2、1.5、2、3 倍速。动作、表情、镜头和音乐可在添加/管理窗口分别设置速度和秒偏移，默认 1/0；速度 0 冻结，正偏移延后、负偏移提前。
- 文件速度与全局倍速相乘。当前音频后端不支持拉伸，音乐有效速度不为 1 时静音；恢复原速后从当前位置起播。详见[播放时序](PLAYBACK_TIMING.md)。
- 停止会将进度复位并恢复原生角色与镜头控制；自定义舞台设置保留，暂停应用。

时间输入可以位于两个采样帧之间。若文件头部时长与末采样时间不一致，播放条会显示两者范围；播放仍使用头部时长。

## 调整动作与镜头

“动作”页的“驱动角色”菜单列出当前场景中的活动角色，一次驱动一个对象。表情身份优先取实际脸模型，再取角色名；旧配置中的手动表情身份覆盖不再生效。目标离场会停止播放并释放接管。

“开发者 → 动作”集中放置实验功能。四角色 Miku 嘴形拟合默认开启，只适用于千奈、麻央、莉波、燕的 base-0000 脸型和保留原始五元音的新导入曲目；旧曲目、未知脸型或不支持的源嘴形沿用原适配。可关闭该实验比较效果。当前视线控制器未接线，相关控件禁用；VMD 自带眼动仍按原轨道播放。

位置偏移采用世界坐标，单位为米。修改即时作用于当前驱动对象，切歌保留，停止恢复场景原位。点击“保存初始位置为默认”后，下次启动使用保存值。

“镜头”页与播放器使用同一组下拉选项：

| 模式 | 行为 |
| --- | --- |
| 游戏 | 释放 GakuMotion 镜头接管，保留镜头参数 |
| VMD | 播放曲目运镜；没有可用轨道时保持机位 |
| 跟随 | 镜头和注视点随角色移动 |
| 注视 | 镜头位置固定，注视点追随角色 |

跟随和注视可选择髋部、胸部或头部，默认髋部。“追随速率”控制追近响应，0 冻结、0.1 平滑、1 即时；高级“位移比例”仍控制各轴位移幅度。旧配置缺少速率时采用 0.1，需要原来的即时跟随可设为全 1。部位暂时不可用时会等待或保持最后镜头并提示。

需要游戏手动取景时，选择“游戏”，再操作游戏镜头。镜头参数即时生效，“保存镜头设置”写入下次启动默认值，作用于全部曲目。高级设置中的场景范围是手工设定的世界坐标边界，不检测墙体碰撞。旧固定模式配置会迁移为 VMD。

## 舞台与物理

“舞台”页提供背景显示、纯色背景及高级场景节点控制。尚未完成的摄影舞台替换只在开发者模式显示，选择会跨区域和重启保留，并在下次游戏原生背景载入时生效；恢复原生背景也需要重新载入。实验舞台选择不表示完整灯光已经实现。

“设置”页选择关闭、内建物理或实验性原生物理。新配置默认选择原生物理，原生接口不可用时回退到内建弹簧骨；内建方案不包含官方碰撞模型。旧配置明确保存的后端选择继续保留。页面上的后端选择不表示原生物理已实际运行。

腰部支撑默认开启，可在“开发者 → 动作”关闭并恢复原姿态；旧配置明确保存的关闭状态仍有效。

开启“开发者模式”后会显示“[开发]”页，鞋底测量、探针与实验开关集中在这里。鞋底测量依赖代理鞋型和场景地面校准；Foot pitch 实验默认关闭，尚不作为通用穿地修正功能。

## 已知兼容性

VR 模式下，GakuMotion 运镜仍有已知兼容问题；桌面模式可用不能推导 VR 组合已通过验证。遇到镜头冲突时先停用 Motion 镜头接管，并在反馈中注明 VR 状态。早期处理过程见[镜头共存历史记录](history/VRIFY_CAMERA_BEGIN_20261027.md)。

四角色嘴形拟合仍是实验效果，尚未完成游戏内视觉验收；支持脸型之外不会应用该拟合。相机平滑、部位选择与时序控制的离线回归通过，不代表所有角色、服装及 VR 组合的画面均已验证。

目标腿部几何重烘焙尚未移植到当前原生导入器；`unsupported_target_geometry` 会明确失败并保留已有资源。实验性物理与鞋底 pitch 的适用边界以页面说明为准。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+M` | 唤出或唤回控制窗口 |
| `F9` | 播放、暂停或继续当前曲目 |
| `F10` | 停止并恢复原生状态 |
| `,` / `.` | 上一曲 / 下一曲 |
| `-` / `=` | 后退 / 前进 5 秒 |
| `F11` | 重新加载骨骼微调 |
| `Ctrl+F11` | 切换骨骼微调启用 |

播放快捷键需要焦点位于游戏或插件窗口、当前场景允许控制，且面板未在编辑文本。`F8` 和部分标点键用于辅助骨、视线或姿态诊断，排查时需记录当前模式，避免把诊断切换当作通用修复。
