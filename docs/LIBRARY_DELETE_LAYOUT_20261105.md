# 曲库永久删除与窗口布局修订

日期：2026-11-05

## 用户可见行为

曲库删除入口统一为“删除选中”。确认窗显示曲名和目录，点击“永久删除”后删除整个曲目目录及其全部文件；取消、Esc 或关闭确认窗不删除文件。删除不再移动到 `.gakumotion-trash`，不再提供列表隐藏和两种恢复按钮。

旧播放列表的隐藏记录不再生效，原位置仍存在的曲目会在扫描后显示。旧版 `.gakumotion-trash` 保持原样、继续跳过扫描；本轮不处理其中的用户文件。

主窗口按可用高度分配内容和播放条；添加/管理窗口随字体和屏幕高度调整，操作按钮保持可见，空间不足时只滚动表单。高级场景编辑的已探测节点列表使用页面剩余高度，随窗口伸缩。

## 实现与来源范围

从当前发布源码分别应用曲库删除、旧播放列表兼容和 GUI 布局改动，保留该仓已有产品范围。没有整仓同步研发内容，也没有引入 Control/Clock/Timeline/Director、Studio 布光/视频、眼动研究、真实素材或用户工作区临时文件。原有必需输入、参数和第三方许可保持原身份。

永久删除保留曲库根、直接子目录、曲目标识、版本及链接/重解析路径检查。文件系统无法保证递归删除完全原子化；异常部分失败时按实际磁盘状态刷新并提示，文件已删除后列表保存失败也单独报告。
