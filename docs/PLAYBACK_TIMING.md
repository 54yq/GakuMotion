# 播放时序

全局倍速推进演出时间；动作、表情、镜头、音乐各自按以下关系采样：

```text
源时间 = max(0, (演出时间 - 秒偏移) × 文件速度)
```

文件速度默认 1、秒偏移默认 0。速度必须为不小于 0 的有限数值，0 表示冻结首帧；正偏移延后，负偏移提前。跳转、逐帧定位和循环使用相同映射，演出时长取所有有效轨道的末端。

添加或管理窗口保存参数到曲目 `info.json` 的 `track_timing`；编辑已有曲目不改写源媒体。保存后点击“重新加载当前曲目”使用新参数。旧曲目没有该字段时按 1/0 播放。

| 字段 | 内容 |
| --- | --- |
| `motion` | 身体动作 |
| `facial` | 表情及来自表情文件的眼轨 |
| `camera` | 运镜 |
| `audio` | 音乐 |

每项含 `speed` 和 `offset_seconds`。当前音频后端无法拉伸音乐，有效速度不为 1 时静音，恢复原速时从当前位置起播。音乐结束不会阻塞较长的动作或镜头。

本版 Runtime 与 NativeAOT 必须成对更新：身体导入 ABI 3、镜头 ABI 1。
