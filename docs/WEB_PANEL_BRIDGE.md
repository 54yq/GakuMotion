# GakuMotion 4.3 Web 看板

曲库、底部播放控制、镜头和舞台页面来自 GakuMotion dev 的 `79fe245`。Web 资源安装位置是运行时 DLL 旁的 `GakuMotion.UI/`。运行时发布 `gakumotion.web-panel/v1`，由支持该接口的 GakuLoader 管理 WebView2。此次编译使用 Gaku-Mod-Tools/GakuLoader dev 的 `157cfb0`，其 `version.dll` 与 `WebView2Loader.dll` 为一组。原生 ImGui 回调仍在，调试时可在启动进程的环境中使用 `GAKUMOTION_NATIVE_PANEL=1` 进入原生面板。

## 4.3 功能如何映射到界面

- **曲库和底栏**保留上游列表与播放布局。曲库也能按本地文件夹过滤，并沿用 4.3 对外部文件的删除保护。底栏的「精细控制」提供按时间、按帧和逐帧定位，曲库、Live 与站位共用同一个动作播放栏。
- **Live 接管**在普通 Live 已识别时提供入口，包括接管或退出恢复、原 Live 暂停、进度、循环和 16:9 试验。未取得动作控制权限时，只显示当前 Live 可执行的操作。
- **动作 → 多人舞台**沿用上游的可折叠区块和角色卡片。角色卡按当前场景识别模型，支持动态添加副角色槽、独立绑定曲目、同步偏移、XYZ 站位、朝向、模型显隐、按名称分配、原曲对齐和队形保存载入。角色名单、曲库或场景变化后，旧请求会被拒绝。
- **原生诊断**仍可在 ImGui 面板使用。上游摄影棚和上游多人舞台的独立运行逻辑没有引入。4.3 的旧导入器不支持副标题写入，所以 Web 导入对话框隐藏该项。

## 验证方式

`fork.get` 返回当前场景、Live、角色名单、曲库版本和队形快照。 Web 通过 `fork.command` 复用 4.3 的 GUI 回调与主线程队列。角色站位使用绑定代次校验，Live 使用场景和所有者标识校验。

`tests/test_fork_web_panel.cpp` 用合成状态验证原生桥接。`frontend/scripts/preview-fork.mjs` 从独立预览构建生成可本地打开的 HTML 和界面图。设计预览使用模拟曲目与角色，没有读取游戏数据。独立预览和离线契约覆盖交互及请求，游戏内角色绑定、WebView2 拖放和退出接管后的画面仍需实机验收。
