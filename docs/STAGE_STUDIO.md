# 摄影布光与本地视频（实验）

入口：开启开发者模式，进入 **开发 → 布光与视频**。不在摄影中时，也可在禁用页面的开发者选项中编辑预设。

两个功能默认关闭。勾选启用、调整参数后，分别点击 **应用布光设置** 或 **应用视频设置** 才会保存。设置跨区域和重启保留，仅在有效的偶像摄影场景应用；离开摄影后不继续向其他场景注入。

## 自定义布光

- 主光、补光、轮廓灯各使用一个独立 Spot 聚光灯，可调整颜色、强度、水平角和俯仰角。
- **人物风格光**调整人物光照 profile，人物受光强度与人物轮廓光可单独调节。
- **已有背景装饰灯**为可选项，调整场景中已有 Decal 灯的染色与强度倍率；没有对应灯具时不会凭空补出原生灯效。

建议先只启用布光，应用默认参数，再分别修改主光颜色和强度观察变化。此首版为自定义静态布光，不播放官方灯光时间轴。

## 视频输入与独立幕布

进入 **视频输入/幕布实验**，浏览或输入本地视频的完整路径，勾选 **启用视频输入**，然后点击 **应用视频设置**。视频独立静音播放，与动作、音乐及游戏原生大屏互不绑定。

幕布以本次创建时首次读取的摄影相机位姿为固定锚点，之后移动相机不会让幕布随镜头移动。**幕布距离、宽度、水平偏移、垂直偏移**用于摆放画面，视频宽高比用于确定幕布高度。需要重新取相机锚点时，先停用视频，调整相机，再重新启用并应用。

**暂停视频**与**循环视频**也需点击应用后生效。暂停保持视频自身进度；首版尚未与 MMD 进度同步。

可用自备测试片检查幕布的可见性、方向、比例、暂停和循环。能选择文件仅表示路径可用，编码支持以运行时状态及画面为准。

## 停用与恢复

**停用自定义布光**、**停用视频输入**分别保存关闭状态，保留参数与所选文件。**恢复布光与视频默认值**会关闭两个功能并重置全部参数。设置保存在活动配置目录的 `stage_studio.json`。

此开发线通过离线测试覆盖设置、文件选择、对象所有权、灯光恢复和视频生命周期。实机验收还需覆盖画面、不同角色与背景、停用及跨场景恢复。状态日志 `stage_studio_status.json` 可用于查看当前所有权和解码状态。

已知摄影相机排除默认第 0 层；首版从当前场景实际几何/全局 Volume 与相机 mask 选择可见层，歧义时显示失败或降级，不修改相机 mask。幕布默认距创建时镜头 1.5 米、宽 1.2 米；如被背景遮挡可减小距离，再调整宽度和偏移。首轮通用舞台的远距离幕布尚未视觉通过。
