# GakuMotion 分支更新记录

插件显示 `v<上游版本>+fork.<分支版本>`，Git 标签使用 `fork-v<分支版本>`。分支版本按自己的节奏递增。

## 分支 v4.3.30-web

- 原生物理诊断增加 Swing 返回点的左前发骨局部旋转，并通过原生输入帧号关联角色回调样本。

## 分支 v4.3.29-web

- 服装物理逐帧诊断记录主角头骨和采样骨骼父骨的世界旋转，并附上帧间隔。

## 分支 v4.3.28-web

- 接管仍在运行、且已核验含两个 Campus 作业、无动作片段的角色原图时，暂停原图并使用仅含一个 Campus 作业的独立图继续原生 Swing。停止独立图后恢复所借用原图的播放状态。

## 分支 v4.3.27-web

- 单角色 Live 接管播放时，按角色记录未接管角色的原图是否保持暂停，供多人舞台物理对照使用。诊断只读取原图状态。

## 分支 v4.3.26-web

- Web 看板的「连续记录手臂与服装骨」在 Live 接管时可触发一次 15 秒逐帧物理采样。采样期间暂停原有低频快照，减少额外负载。

## 分支 v4.3.25-web

- 服装物理诊断增加原生模式，短时记录主角头发和衣摆在插件角色更新前后的局部旋转，并附带原生输入帧和步长。内建模式使用同一采样点作为对照。

## 分支 v4.3.24-web

- Live 原生物理播放时，按已确认消费的 Swing 输入对齐主角和跟随位的身体骨骼。下一帧的动作姿态仍按原时序发布给原生求解器。

## 分支 v4.3.23-web

- 基于 4.3.22-web 同步构建原生插件和网页面板，包含三路角色打光 1000% 手动上限及方向调节。

## 分支 v4.3.22-web

- 暂停接管中的动作时，释放主角和跟随位的物理输入，停止独立角色时钟。恢复播放时重新建立物理输入。
- 慢帧日志记录动作状态和上一帧的插件帧回调、角色回调耗时。

## 分支 v4.3.21-web

- 角色主光、暗部补光和轮廓光的手动强度上限统一为 1000%。

## 分支 v4.3.20-web

- 角色三路打光强度开放 HDR 数值，主光与轮廓光可调方向。读取主角打光与恢复默认并排放在强度下方。

## 分支 v4.3.19-web

- 添加到曲库对话框右上角只保留「导入文件」，各轨道仍可单独浏览。

## 分支 v4.3.18-web

- 添加到曲库时可直接选主动作，标题默认沿用动作文件名。自动列出同目录的 WAV 和含镜头的 VMD 或 GKCamera。
- 追加文件保留候选列表用途，尚无主动作时可自动选中追加的有效动作。
- 删除确认框内的长路径可换行，操作按钮保持在弹窗内。

## 分支 v4.3.17-web

- 角色固定打光可分别调整主光、暗部补光、轮廓光颜色，并混合当前 Live 的原场角色光照。

## 分支 v4.3.16-web

- 「舞台 → 舞台视觉控制」新增独立的 Paraffin 镜头光晕和 Live 景深开关。景深保留 VMD 自动关闭规则，也可在当前场次手动覆盖。

## 分支 v4.3.15-web

- Live 接管时，缺少眼睑轨道的动作使用睁眼待机和自然眨眼。有眼睑轨道的动作继续驱动眼睑。

## 分支 v4.3.14-web

- 多人舞台支持直接交换两个已绑定副角色。保留各槽位的动作和时间偏移，卡片单独显示当前实际绑定的人物。
- 同一场 Live 新增人物后，现有和新槽位仍可修改绑定。

## 分支 v4.3.13-web

- 固定打光默认采用主光 40%、暗部补光 3.5%、轮廓光 25%。Live 接管时可读取并应用主角色所在场次的原生角色光照参数。

## 分支 v4.3.12-web

## 分支 v4.3.11-web

## 分支 v4.0 · 2026-11-19

本版基于 crested-ezios 的 GakuMotion v0.1.1，由野生的空白维护。插件显示 `v0.1.1+fork.4.0`，对应 Git 标签 `fork-v4.0`。

- **多人演出与站位**。按需添加角色槽位，各角色绑定动作与原生物理输入，随主角统一播放进度。支持单独调整站位和朝向、以主角色对齐原曲队形，以及与 GakuActors 加载的角色配合。
- **Live 接管**。暂停原舞台后使用当前主角播放 Motion。将原 Live 动作及表情片段停在结尾后一帧，保留角色图时钟及头发、服装的原生 Swing 解算。同一角色切曲、暂停或拖动进度时保留锁定，在新 Live 启用接管时按新角色图建立时钟。锁定验证接受 Unity 将片段夹回精确末尾的情况。
- **服装与动作**。修正进度回退时的原生服装物理交接，收尾移除了临时袖骨和蒙皮探针。支持按角色校正前臂、重定向烘焙腿骨，以及分别配置动作源帧率和输出采样率。
- **镜头与舞台**。支持镜头跟随主角朝向、Live VMD 对齐、与自由视角交接，以及实验性的 Live 景深、风场、道具显隐和卡顿监测。

本地这轮服装物理工作有 18 个 Git 检查点（包含起始快照）和 14 个安装备份点。较早的多人、镜头和 Live 改动来自其他开发历史。
