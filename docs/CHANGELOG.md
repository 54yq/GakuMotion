# GakuMotion 分支更新记录

插件显示 `v<上游版本>+fork.<分支版本>`，Git 标签使用 `fork-v<分支版本>`。分支版本按自己的节奏递增。

## 分支 v4.3.1

- 「动作 → 场景道具」支持手动重新扫描，识别带 `(Clone)` 的配对道具，以及直接挂在角色骨骼和模型节点下的已知道具。
- Live 接管的 16:9 画幅保留横向构图和镜头距离，通过打开上、下方的取景范围填满原有黑边。
- 舞台节点已达到目标显隐状态时跳过重复写入，道具后台扫描降低频率，桌面面板在游戏线程忙碌时跳过当前界面帧。风场、黑边和音频图的后台诊断默认关闭。创建 `GakuLoader/Configs/gaku-diagnostics.enabled` 后重启可恢复这些诊断。

## 分支 v4.3 · 上游整合

- 基于本地 `fork-v4.2.1`，整合上游 `main` 的 `39f1f9a`。继续使用导入 ABI v4 和本地自动站位的曲目原点读取接口。
- 移植上游 `dev` 的表情适配服务和旧曲目口形轨道恢复。安装配套新版 NativeAOT 导入器可读取保存的 VMD 口形轨道。外部表情拟合需要可用的 provider。
- 原生面板在窄窗口改用顶部导航。表情倍率集中在「动作 → 表情幅度」，16:9 画幅实验集中在「Live 接管页面」，和返回曲库、退出接管及诊断入口放在一起。
- 构建按版本号选取完整 Windows SDK，无音频设备的测试仍验证 Unicode 文件路径。WebView2 看板及依赖它的桥接服务未随本版部署。

## 分支 v4.2.1 独立角色图实验版 · 2026-11-20

基于 v4.2，包含 Live 16:9 测试开关和场景道具扫描。接管时尝试为原主角的 Animator 和原服装骨架创建独立的原生 Swing 图，并使用现有 Motion 表情写入。独立图校验或求解确认失败时，在清理新图后尝试结尾后一帧方案。详见[独立角色图实验记录](LIVE_INDEPENDENT_ACTOR_GRAPH_PROBE.md)。

## 分支 v4.2 Live 画幅测试版 · 2026-11-19

本版基于 v4.1.1，包含场景道具扫描和独立角色图诊断。插件显示 `v0.1.1+fork.4.2`，对应 Git 标签 `fork-v4.2`。

- 普通 Live 接管时可将相机渲染目标和 Live 界面一起切换到 16:9。通过接管面板的测试开关对照同一帧，退出接管时恢复原画幅。日志记录相机像素区域、投影和界面比例。

## 分支 v4.1.1 · 2026-11-19

基于 v4.1 的独立角色图只读诊断构建。读取原角色图和已存在的自定义图，记录自定义图的 Animator 归属、原生 Swing 作业和动画片段。诊断期间仍使用现有的结尾后一帧接管方式。详见[独立角色图调查](LIVE_INDEPENDENT_ACTOR_GRAPH_PROBE.md)。

## 分支 v4.1 · 2026-11-19

- 进入受支持的场景后自动扫描角色道具，统一显示在 **动作 → 场景道具**。Live 接管前可以查看列表，接管后可以调整显隐。
- 扫描角色模型子层级中的道具，识别麦克风、行李箱、荧光棒、水枪和糖果。其他符合配对规则的道具保留原始节点名。
- 道具操作按角色实例和道具实例核验。行李箱的节点和网格分别保存和恢复原有显隐状态。

## 分支 v4.0 · 2026-11-19

本版基于 crested-ezios 的 GakuMotion v0.1.1，由野生的空白维护。插件显示 `v0.1.1+fork.4.0`，对应 Git 标签 `fork-v4.0`。

- **多人演出与站位**。按需添加角色槽位，各角色绑定动作与原生物理输入，随主角统一播放进度。支持单独调整站位和朝向、以主角色对齐原曲队形，以及与 GakuActors 加载的角色配合。
- **Live 接管**。暂停原舞台后使用当前主角播放 Motion。将原 Live 动作及表情片段停在结尾后一帧，保留角色图时钟及头发、服装的原生 Swing 解算。同一角色切曲、暂停或拖动进度时保留锁定，在新 Live 启用接管时按新角色图建立时钟。锁定验证接受 Unity 将片段夹回精确末尾的情况。
- **服装与动作**。修正进度回退时的原生服装物理交接，收尾移除了临时袖骨和蒙皮探针。支持按角色校正前臂、重定向烘焙腿骨，以及分别配置动作源帧率和输出采样率。
- **镜头与舞台**。支持镜头跟随主角朝向、Live VMD 对齐、与自由视角交接，以及实验性的 Live 景深、风场、道具显隐和卡顿监测。

本地这轮服装物理工作有 18 个 Git 检查点（包含起始快照）和 14 个安装备份点。较早的多人、镜头和 Live 改动来自其他开发历史。
