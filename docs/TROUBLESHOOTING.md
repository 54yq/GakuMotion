# 故障排查

遇到问题时，建议先厘清故障发生的具体阶段：插件宿主加载、场景与状态准入、资产导入还是动作/运镜播放。GakuLoader 宿主日志与游戏内面板状态可以明确区分这些环节。

> ⚠️ **提示**：更新或替换任何 DLL 文件后，必须**完全退出游戏进程并重新启动**，热替换或游戏运行中覆盖无法生效。

---

## 1. 加载

### F1 快捷键无法呼出 GakuLoader 菜单
1. **确认入口**：确认游戏根目录下的 `version.dll` 来自配套的 [GakuLoader](https://github.com/crested-ezios/GakuLoader) 运行包，且覆盖后已重启游戏。
2. **窗口焦点**：确保鼠标已点击游戏画面内部获得操作焦点，再按 **F1**。
3. **排查日志**：检查是否存在 `GakuLoader/Logs/gakuloader.log`：
   - 若完全没有日志生成，说明 `version.dll` 未被系统加载（请检查 VC++ 2015–2022 x64 运行库或防病毒软件拦截）。
   - 若已有日志生成，检索内部是否存在初始化或窗口挂钩错误。

### F1 菜单可以打开，但列表中没有 GakuMotion
1. 确认 `GakuMotion.dll` 与 `GakuMotion.VmdImporter.Native.dll` 均已放入 `GakuLoader/plugins/` 目录。
2. 两个 DLL 必须来自同一版本，版本不匹配会导致加载被拒绝。
3. 查阅 `gakuloader.log` 中关于 `GakuMotion` 的加载记录，排查是否存在依赖缺失或签名校验失败。

---

## 2. 面板

### 按快捷键没有反应或面板显示禁用
1. **呼出热键**：进入偶像摄影模式后，按 **Ctrl+M** 唤回或聚焦 GakuMotion 控制面板。
2. **场景与页面准入限制**：
   - GakuMotion 仅在 **“偶像摄影”** 和 **更衣室** 下接管动作与镜头。
   - 主界面、P 培育流程、常规 Live 演出、剧情对话以及未被插件识别的特殊摄影背景下，引擎处于受保护状态，面板会明确显示禁用。
3. **手动拍照保护机制**：
   - 若场景进入时黑屏数秒，或日志报告“手动拍照保护未就绪”，说明游戏原生的摄影相机或动作机尚未初始化完毕。该限制属于安全防崩保护，无法通过强行调节播放参数绕过，稍等片刻或重新进入摄影场景即可。

> GakuMotion 仅在本地对演出运行时进行内存接管，**不包含任何网络 Hook**，亦不需要通过断网来触发功能。

---

## 3. 曲库

### 曲库为空，或外部放入的文件没有显示
全新安装时，所有曲目应放置在 `GakuLoader/PluginData/gakumotion/motions/` 的**直接子目录**中：
```text
  motions/
    └── MyDance/
        ├── motion.gkclip (或 .gkmotion / .gk_world_dump)
        └── song.wav (可选伴奏)

```

多嵌套一层文件夹会导致扫描索引忽略该曲目。**建议将导入曲目交由GUI交互界面管理，避免手动放置文件**。

* **刷新 vs 重载**：
* 点击“**刷新曲库**”：仅重新遍历磁盘目录更新下拉列表，不会打断或替换当前内存中正在运行的表演。
* 点击“**重新加载当前曲目**”：重新读取当前曲目的磁盘文件并即时刷新，同时保留当前的播放进度与暂停状态。


* **条目选中与加载状态**：在列表中高亮条目仅为“选中浏览”；需点击“**加载预览**”或“**播放选中**”，数据才会正式写入运行时。
* **删除操作提示**：在面板中点击“删除选中”并二次确认后，将**直接永久删除磁盘上的对应曲目文件夹**，不可撤销，请谨慎操作。

## 4. VMD导入

| 报错现象 / 提示信息 | 根本原因与排查方案 |
| --- | --- |
| **找不到配套导入器 / DLL 无法加载** | 检查 `GakuMotion.VmdImporter.Native.dll` 是否丢失，必须与 `GakuMotion.dll` 成对更新并放置于 `plugins/` 目录。 |
| **缺少 ABI v2 或独立镜头 ABI v1** | 导入器动态库版本与插件核心不一致，请从同一发布包中完整替换后重启。 |
| **所选 VMD 不包含所需关键帧** | VMD 骨骼/表情/相机类型不匹配。纯表情或纯运镜的 VMD 无法作为身体主动作导入。 |
| **曲名已存在** | 磁盘已存在同名曲目目录。请更换曲名，或使用“管理选中”更新覆盖现有曲目。 |
| **音频不是 PCM WAV** | 音频文件必须为标准的未压缩 **PCM 编码 WAV**。直接将 `.mp3` 改后缀为 `.wav` 会导致解码器拒绝解析。 |

## 5. 播放

### 只有动作没有声音

确认曲目目录下存在标准的 `song.wav`。

* 使用自动导入时，插件优先检索同名 WAV 或旁边的 `song.wav`。

### 变速播放时音频静音

当全局播放倍速与音频速率换算后**不等于 1.0 时，系统会自动静音**，以避免音频重采样引发的声音撕裂或引擎时钟失步。

### 镜头不动或无法手动调整视角

* **固定机位状态**：若曲目中未包含相机轨道（或未勾选运镜接管），虚拟相机会保持在当前摄影棚的基准机位。可通过“管理选中”补充镜头 VMD 或 `.gkcamera` 文件。
* **手动取景冲突**：GakuMotion 接管镜头后会屏蔽原生手柄/键盘的相机移动。如需手动构图，请先在面板关闭运镜接管，调整完毕后再重新开启。
* **边界约束与 VR 说明**：
* 勾选“限制镜头在场景范围内”仅按配置的世界坐标立方体进行硬截断，不具备物理网格碰撞检测。
* 当前版本在 VR 自由空间模式下的相机调度存在已知渲染边界冲突，建议优先在桌面模式下录制运镜。

### 播放动作时，游戏内的拍照按钮没有反应

异常照片流入官方服务器会显著增加你的账号以及当前项目的风险。出于安全考虑，在插件介入画面后，拍照按钮将被禁用。如需拍照，请使用系统截图功能。

## 6. 姿态、表情与物理表现异常

* **基准适配说明**：Technical Preview 阶段优先支持花海咲季（Hanami Saki）的骨骼解算与微表情转译。其他角色的极端形变、特殊骨骼比例以及部分长发/长裙物理，正在分批次进行参数校准。
* **报告异常**：若发现关节严重翻折、表情锁死或穿模，请利用面板的**暂停与逐帧步进功能**定位到具体的动作帧数，并附带角色与服装提交 Issue。

---

## 7. 日志收集与问题反馈

所有诊断日志均输出在游戏根目录的 `GakuLoader/Logs/` 下：

| 日志文件 | 记录内容 |
| --- | --- |
| `GakuLoader/Logs/gakuloader.log` | 插件加载时序、场景准入判定、状态机保护、运行时异常 |
| `GakuLoader/Logs/gakumotion/import.log` | 身体骨骼、表情、视线转译与整曲资产导入流 |
| `GakuLoader/Logs/gakumotion/camera_import.log` | 独立运镜轨迹导入与相机参数解析日志 |
