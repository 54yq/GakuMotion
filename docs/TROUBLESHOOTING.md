# 故障排查

先确认问题发生在插件加载、场景准入、素材导入还是播放阶段。面板状态与日志能区分这些环节；替换 DLL 后需正常退出并重新启动游戏，才能检查新版行为。

## F1 宿主管理窗口没有出现

1. 确认游戏根目录的 `version.dll` 来自当前 [GakuLoader](https://github.com/crested-ezios/GakuLoader)，并已重新启动游戏。
2. 让焦点位于游戏窗口，再按 `F1`。若没有 `gakumas-local/gakuloader.log`，先按 Loader 的安装说明核对宿主加载；若已有日志，检查启动和窗口错误。
3. 若 F1 能打开但列表没有 GakuMotion，确认两个配套 DLL 位于 `gakumas-local/plugins/`，查看日志中的插件加载结果。单独出现导入器文件不能代替 `GakuMotion.dll`。

## 面板打不开或显示禁用

1. 检查 GakuLoader 是否加载了 `plugins/GakuMotion.dll`，以及两个 GakuMotion DLL 是否来自同一构建。
2. 进入偶像摄影，按 `Ctrl+M` 唤出窗口。这个快捷键用于唤回窗口，不是关闭开关。
3. 若面板显示禁用，查看页面准入与手动拍照保护提示。主页、Live、培育、未知页面和未识别的摄影背景不能接管。
4. 若日志报告手动拍照保护未就绪，保留错误记录；修改播放或镜头设置不能绕过该条件。

当前支持范围见[使用指南](USAGE.md#打开面板)。GakuMotion 不安装网络 Hook，也不以断网作为接管条件。

## 曲库为空或文件更新没有生效

每个曲目应位于当前曲库根的直接子目录，包含 `motion.gkclip`、`motion.gkmotion` 或 `motion.gk_world_dump`。未迁移时根为 `gakumas-local/motions/`；完成[分类目录迁移](MIGRATION_LAYOUT.md)后为 `gakumas-local/UserData/gakumotion/motions/`。多套一层目录会导致扫描不到曲目。活动回执损坏或根不匹配时会拒绝加载，不会改读旧目录；先保留回执和迁移清单再排障。

外部增删文件后使用“刷新曲库”。刷新只更新列表，不替换已经加载到内存的表演；当前曲目的文件变化需再点击“重新加载当前曲目”。重新加载保留时间，并保持暂停或预览。若提示源文件已移除，先恢复文件再重载。

单击列表只浏览条目。播放列表中的选中曲目与底部播放条显示的当前已加载曲目可能不同；使用“加载预览”或“播放选中”明确加载。

此前使用“从列表移除”隐藏的条目，可点“恢复已移除曲目”；文件删除后的恢复使用“恢复最近删除”。若提示同名冲突，先重命名或移走当前同名目录，再恢复，避免覆盖新曲目。恢复区在 `motions/.gakumotion-trash/`，不作为普通曲目扫描。

## 导入失败

| 提示或现象 | 检查方法 |
| --- | --- |
| 找不到配套导入器或 DLL 无法加载 | 将同一构建的 `GakuMotion.VmdImporter.Native.dll` 放在插件目录，退出游戏后成对更新 DLL |
| 缺少 ABI v2 或独立镜头 ABI v1 | 导入器版本与插件不匹配，成对更换后重启 |
| 所选 VMD 不包含所需关键帧 | 身体、表情、镜头各自使用对应内容；纯表情或纯镜头 VMD 不能充当新增曲目的身体动作 |
| 曲名已存在 | 新增版本使用不同曲名；更新已有曲目使用“管理选中” |
| 音频不是 PCM WAV | 使用真正的 PCM WAV，修改扩展名不能把 MP3 等格式转换为 WAV |
| `unsupported_target_geometry` | 当前原生导入器尚未实现已绑定 `target_leg_geometry.json` 的目标腿部几何重烘焙；该请求会明确失败并保留已有曲目 |

产品导入不会启动 Python，也不会在失败后回退到 Python。旧资料中安装 NumPy/SciPy 或修改 `import_backend` 的操作不适用于当前产品导入流程。Python 仍用于开发者的离线研究与对照。

## 没有声音或速度没有变化

曲目音频的播放文件名为 `song.wav`，位于曲目目录。检查是否选择了“不导入”、是否开启静音，以及输入文件是否为 PCM WAV。自动音频选项只查找身体 VMD 同名 WAV 或旁边的 `song.wav`。

音频路径使用 Windows 宽字符接口；部分旧 waveaudio 驱动仍拒绝特殊 Unicode。新版只读尝试同文件已有的短路径别名，没有可用别名时保留明确 MCI 错误，不会改名或复制用户音频。

逐帧、加载预览和暂停定位保持静默。有声播放跟随音频时钟，改变动作预览速度不会改变歌曲速度。外部替换音乐后，需要重新加载当前曲目才能使用新文件。

## 镜头不动或不能手动取景

选择 VMD 镜头但曲目没有可用的运镜轨道时，会保持固定机位。使用“管理选中”补充镜头 VMD 或 `.gkcamera`，保存后检查面板提示。

GakuMotion 接管镜头时会限制游戏手动镜头输入。需要重新取景，先停用镜头接管，调整游戏机位后再启用。“限制镜头在场景范围内”只按手工配置的世界坐标边界约束，不能代替墙体碰撞检测。

VR 与桌面镜头的调度有不同边界，桌面模式可用不能推导 VR 已验收。报告问题时注明 VR 是否启用，参考[已知兼容性](USAGE.md#已知兼容性)。

## 姿态、表情或物理不符合预期

先记录曲目、时间或动作帧号、角色、服装、镜头模式与物理后端，并用暂停或逐帧定位固定复现位置。检查驱动对象和表情身份是否匹配；原生物理选项属于实验，界面选择不证明后端已经运行。

内建弹簧骨不包含官方碰撞模型，实验性鞋底 pitch 也不提供通用锁足或穿地修复。导入成功、离线数字一致和实机画面正确分别需要验证。不要仅凭离线测试通过认定动作或角色适配已完成。

停止与恢复使用 `F10` 或底部停止按钮。若异常仍存在，保留日志与复现片段，再正常退出游戏。

## 日志与问题反馈

以下为旧布局路径，相对游戏根目录。迁移后 Motion 的 `import.log`、`camera_import.log` 和时间记录位于 `gakumas-local/Logs/gakumotion/`，诊断位于其 `diagnostics/` 子目录；宿主日志按对应 Loader 版本说明定位：

| 文件 | 内容 |
| --- | --- |
| `gakumas-local/gakuloader.log` | 插件加载、场景准入、保护状态、播放与运行时错误 |
| `gakumas-local/GakuMotion/import.log` | 身体、表情、眼动与整曲导入详情 |
| `gakumas-local/GakuMotion/camera_import.log` | 独立镜头导入详情 |

反馈时提供以下字段；候选包有版本清单时一并附上，未记录的版本填“未知”：

```text
游戏版本：
GakuLoader / GakuMotion / 导入器版本（或 DLL SHA256）：
候选包名称与来源：
复现步骤与实际结果：
期望结果：
报错原文与发生时间：
相关日志片段：
```

视觉问题补充角色／服装、摄影背景、曲目时间或帧号、VR 状态；涉及素材时记录输入文件名称和导入选项。
