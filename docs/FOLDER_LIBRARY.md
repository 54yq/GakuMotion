# 文件夹曲库和多人自动分配

在“曲库”点击“添加文件夹”选择动作目录。Motion 在后台扫描该目录和子目录：已有可用的 `motion.gkclip`、`motion.gk_world_dump` 或 `motion.gkmotion` 直接读取；尚未转换的身体 VMD 依次转换到 Motion 管理的曲库缓存，已经转换过的原始文件不会重复转换。外部源目录按只读处理，删除缓存曲目或移除文件夹来源不会删除原文件。一个目录恰好有一个 WAV 或一个可用镜头时会自动关联；存在多个候选时请手动选择。

“文件夹”选择器按来源目录分组并显示子目录，可切换回“所有文件夹”；“移除文件夹”停止跟踪该来源，保留源文件和已转换缓存。点击“刷新曲库”重新扫描已添加的文件夹。单次扫描最多遍历 20000 项、发现 2048 个待转换动作；无法读取或转换失败的项目会显示状态。

场上角色就绪后，先选择其中一个动作，在“多人同步播放”点击“按名称自动分配”。选歌本身不会更改多人绑定。Motion 在当前动作的原始 VMD 所在目录查找相同曲名前缀的分轨，按照自然文件名顺序分配：例如 A、B 或 01、02、10，第一首分给主角色，其余按场上角色顺序分配。角色多于动作时剩余角色留空；动作多于角色时多余动作不分配。如果文件名无法识别角色编号或字母，按同一目录的动作名称排序；原始 VMD 路径不可用时需手动绑定。

自动分配会替换当前多人绑定，播放或暂停时不可使用。已绑定角色的骨架就绪且原始 VMD 的初始站位可验证时，会尝试按主角色对齐原曲队形；移动过站位则不会再自动覆盖手动调整。可在停止播放后使用“删除角色”移除某个槽位，原有角色模型与动作文件不会被删除。“站位与朝向”展开后可单独微调。
